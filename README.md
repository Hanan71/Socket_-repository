# Real-Time Socket Chat Simulation 💬

A lightweight network communication project demonstrating real-time bi-directional messaging between two endpoints using TCP sockets.

---

## 💡 Overview
This project simulates a peer-to-peer/client-server chat architecture using raw socket programming. It establishes a direct communication channel over a specific IP and port, allowing two parties to exchange instant text messages back and forth.

---

## 🌟 Key Features
* **Bi-Directional Messaging:** Full two-way real-time communication between server and client.
* **TCP Connection:** Reliable, connection-oriented data transfer.
* **Minimalist Architecture:** Clean, readable socket implementation without external dependencies.

---

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Hanan71/Socket_-repository.git](https://github.com/Hanan71/Socket_-repository.git)
   cd Socket_-repository

   1-Start the Server (Terminal 1):
   
   python server.py
   
   2-Start the Client (Terminal 2):

   python client.py
   
Start exchanging messages between both terminal windows.
